# Solo Dining — 个人产品设计展示

参考 Solo Dining 的用餐交互逻辑，融合用户提供图片的奶油白与静物风格。当前目录为独立本地版本，没有修改线上 Netlify 网站。

## 打开

双击 index.html，无需安装依赖。若浏览器对本地文件有限制，可使用任意静态服务器打开此目录。

## 录屏演示顺序

1. 首屏：展示餐具静物与「一个人，也好好吃饭」。
2. 关于：说明侧边凹槽的设计目的。
3. 交互：依次点击「拿起、使用、搁置」，观察筷子和说明同步变化。
4. 拖拽：拖动筷子到凹槽附近释放，再点击「重新体验」。也可点击筷子循环切换。
5. 材质：展示碗、托盘与木质餐具。
6. 视频：选择你自己的项目视频并播放。刷新后需重新选择，文件不会上传。

## 小白修改指南

- 标题、介绍、材质、署名：修改 index.html 中对应中文。
- 颜色：修改 style.css 顶部 :root 中的颜色值。
- 三种状态的说明：修改 script.js 顶部 moments 对象。
- 默认作者信息：可在页脚「个人产品设计概念项目」处换成真实姓名。
- 添加素材与固定视频：查看 assets/README.md。

当前没有真实摄影和视频，所有餐具是 CSS 概念造型。不要把概念材质、结构和动作演示当作实物验证。详细结构与功能边界见 spec.md。
